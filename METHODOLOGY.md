# Scoring methodology

The [Scoring methodology](docs/methodology.md) page is the canonical reference for this project's evidence standard, eight criteria, score calculation, severity bands and symbolic clock. It documents methodology v1.0, with calibration effective 7 October 2026, against the current Python implementation.

The published defaults use Trifecta weights `[0, 1, 3, 7]`, five amplifiers rated 0–2, a weighted incident score of 0–17 and a 900-second starting window that halves every 1,000 cumulative evidence points. The separate unweighted 0–13 total controls the optional report gate. Full definitions, worked examples, calibration provenance and limitations belong in the canonical page.

Start with [Context and rationale](docs/context.md) for the purpose of the index, or [the documentation home](docs/index.md) for the implementation and evaluation guides.
